# Donnerkugel

Murmel-Rätselspiel fürs Handy: Roll die Kugel gegen die Steine und finde alle Farbpaare.

**Spielen:** https://thmenet.github.io/donnerkugel/

- Steuerung: Handy neigen, schnell wischen gibt Schwung (oder per Finger ziehen)
- 8 Level mit Abgründen, Eis, Sand, Glas, Schaltern und Toren

`index.html` ist die spielbare Seite, `donnerkugel.html` die Quelle für die Claude-Artifact-Version.
